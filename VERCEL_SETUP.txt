🚀 DEPLOY IN 3 STEPS
───────────────────────────────────────────────────────────────────────────────

STEP 1: Initialize Git
  $ cd /home/fawad/Desktop/marketplace
  $ git init
  $ git add .
  $ git commit -m "Serverless Walmart API for Vercel"

STEP 2: Push to GitHub
  1. Create repo at https://github.com/new
  2. Name: walmart-marketplace-api
  3. Run:
     $ git remote add origin https://github.com/YOUR_USERNAME/walmart-marketplace-api.git
     $ git branch -M main
     $ git push -u origin main

STEP 3: Deploy to Vercel
  1. Go to https://vercel.com/new
  2. Click "Import" next to your GitHub repo
  3. Click "Deploy"
  4. Wait 1-2 minutes ✨
  5. Get your live URL!

───────────────────────────────────────────────────────────────────────────────
⚙️ IMPORTANT NOTES
───────────────────────────────────────────────────────────────────────────────

1. Vercel Limits:
   - 10 second execution timeout per request
   - Use pagination for large datasets ✓ Already built in
   - Free tier includes up to 100GB bandwidth/month

2. Data Persistence:
   - Data is loaded from walmart-spec.json on each request
   - Each function call reloads the spec (fresh data every time)
   - Perfect for read-only mock API testing

3. Authentication:
   - All /v3/* endpoints require: Authorization: Bearer {token}
   - Any token value works (it's a mock server)
   - Example: Authorization: Bearer test-token-12345

4. CORS Support:
   - All endpoints support CORS
   - Can be called from any frontend
